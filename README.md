# 🛒 বাজার দর (Bazar-Dor)

> **বাজার দর (Bazar-Dor)** হলো একটি আধুনিক এবং রেসপনসিভ নিত্যপ্রয়োজনীয় পণ্যের বাজার দর ট্র্যাকিং ও তুলনা ওয়েব অ্যাপ্লিকেশন। এর মাধ্যমে ভোক্তারা দৈনন্দিন চাল, ডাল, তেল, সবজি, মাছ, মাংস ও অন্যান্য পণ্যের বাজারভিত্তিক সঠিক দরদাম, হ্রাস-বৃদ্ধি এবং পরিসংখ্যান এক নজরে জানতে পারবেন।

## 🚀 প্রধান সুবিধাসমূহ (Key Features)

1. **রিয়েল-টাইম প্রাইস টিকার (Live Price Ticker Marquee):** 
   - ওয়েবসাইটের শীর্ষে চলমান টিকার স্ট্রিপে বিভিন্ন পণ্যের আজকের বাজার দর এবং হ্রাস-বৃদ্ধির শতকরা হার প্রদর্শিত হয়।

2. **দৈনিক হ্রাস-বৃদ্ধি সেকশন (Daily Risers & Fallers):**
   - **“আজ দাম বেড়েছে ▲”** এবং **“আজ দাম কমেছে ▼”** সেকশনের মাধ্যমে শীর্ষ দর বৃদ্ধি ও হ্রাসের পণ্যসমূহ সহজেই চিহ্নিত করা যায়।

3. **বাজারভিত্তিক বিস্তারিত তথ্য ও পরিসংখ্যান (Market-by-Market Price Comparison):**
   - প্রটেক্টেড ডিটেইলস পেজে প্রতিটি পণ্যের বিভিন্ন পাইকারি ও খুচরা বাজারের (কারওয়ান বাজার, নিউ মার্কেট, মিরপুর ইত্যাদি) সর্বনিম্ন, গড় ও সর্বোচ্চ দামের সম্পূর্ণ তালিকা।

4. **স্মার্ট ক্যাটাগরি ফিল্টারিং ও বাংলা সংখ্যা সর্টিং (Category Filtering & Bangla Numeral Sorting):**
   - চাল, ডাল, তেল, সবজি, মাছ, মাংস, ডিম-দুধ ও মশলা ক্যাটাগরি ব্রাউজিং।
   - বাংলা সংখ্যার নির্ভুল নিউমেরিক সর্টিং: *ডিফল্ট*, *দাম: কম থেকে বেশি*, এবং *দাম: বেশি থেকে কম*।

5. **সুরক্ষিত অথেনটিকেশন ও প্রোফাইল আপডেট (Secure Auth & Profile Management):**
   - **BetterAuth** এর সাহায্যে সুরক্ষিত ইমেইল/পাসওয়ার্ড ও সোশ্যাল লগইন (Google, GitHub)।
   - লগইন ছাড়া পণ্যের বিস্তারিত পাতায় প্রবেশ নিয়ন্ত্রণ (Protected Route) এবং প্রোফাইল তথ্য আপডেটের সুবিধা।

## 🛠️ ব্যবহৃত প্রযুক্তিসমূহ (Technologies Used)

- **Framework:** [Next.js](https://nextjs.org/) (App Router, React 19)
- **Language:** TypeScript
- **Styling:** Tailwind CSS
- **Authentication:** [BetterAuth](https://better-auth.com/)
- **Icons:** Lucide React
- **Notifications:** React Hot Toast
- **Deployment Target:** Netlify

## 💻 লোকাল সেটআপ ও রান করার নিয়ম (Getting Started)

১. রিপোজিটরি ক্লোন করুন:
```bash
git clone https://github.com/mahfuzhasan2700/Bazar-Dor.git
cd Bazar-Dor
```

২. ডিপেন্ডেন্সি ইনস্টল করুন:
```bash
npm install
```

৩. ডেভেলপমেন্ট সার্ভার চালু করুন:
```bash
npm run dev
```

৪. ব্রাউজারে ওপেন করুন:
```
http://localhost:3000
```
